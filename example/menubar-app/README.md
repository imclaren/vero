# macOS example

A SwiftUI menu bar app driving the Go worker in `../worker`.

```bash
./build.sh
./.build/debug/MenuBarExample
```

Look for the icon in the menu bar.

[The front ends](../../docs/front-ends.md#a-mac-app-by-hand-in-xcode)
adds vero to a macOS app of your own in Xcode, starting from the Go
worker.
